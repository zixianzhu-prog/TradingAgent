# 同类开源 Agent 学习与升级建议

更新时间：2026-11-09

## 结论

当前系统已经是一个可定时运行、抓取信息、生成候选、调用市场模型、保存预测并回填结果的研究 Agent，
但还不是可证明有效的投资模型，也不应连接真实交易。Serenity 已进入候选门槛、反方论点、财报验证和事件重审，
但供应链图、客户依赖和卡位证据仍有人工维护部分，因此尚未“完全自动融入”。

## 借鉴的公开项目

| 项目 | 值得学习的能力 | 本系统的对应升级 |
| --- | --- | --- |
| EventAlpha-LM | 事件结构化、交易日对齐、防止未来信息泄漏 | 为每个事件保存观测时间、来源和可用交易日；评测只使用当时已知信息 |
| EventEdge | 财报、监管、临床、合作、融资、供应链等多类事件策略 | 扩大 AI Medicine 的 FDA、ClinicalTrials、SEC 8-K/Form 4、政府合同和专利来源 |
| FinSignal-RAG | 对比新闻情绪与 SEC 正式披露，寻找矛盾 | 加入“新闻叙事 vs 财报/SEC”差异检查，矛盾时降低置信度而非加分 |
| financial-agent | 对数字、引用和陈述做独立评测 | 每份报告增加 claim-level 引用覆盖率、数字核对率和来源新鲜度 |
| awesome-finance-agents | 将研究、监控、执行、评测分层 | 不继续无目的堆仓库；优先补证据质量和历史验证 |

## 本次已完成升级

- 新增 `scripts/serenity_gate_engine.py`，由门槛状态自动计算 `research-ready / watch / reject / revalidate`。
- 供应链图、客户依赖和财报验证被设为硬门槛；反方论点也是进入研究候选的必要条件。
- 重大事件只让受影响门槛变成 `stale`，不会自动改成买入或卖出。
- 新增 `outputs/serenity-gate-audit.md`，显示自动结论、证据完整度、缺失硬门槛和人工结论冲突。
- UI 数据改为优先采用自动门槛结果。
- 新增 3 个门槛测试；项目测试总计 39 个通过。
- 事件任务新增 `publishedAt / discoveredAt / knowledgeAt / firstEligibleResearchDate`，只允许在信息真正可知后的下一个工作日进入研究。
- 新增 TEM、SDGR、RXRX、ABCL 四家公司的 SEC EDGAR 官方 Atom feed。
- 修复 SEC 跨公司误去重：相同的 `10-Q`/`8-K` 标题不会再让一家公司的披露覆盖另一家公司。
- 当前项目测试总计 41 个通过；四个 SEC feed 已实际联网验证。
- 新增新闻叙事与官方披露差异检查：只有“乐观非官方叙事”和“官方风险证据”同时存在时才标记差异，避免把单一关键词直接当成事实矛盾。
- SEC `10-Q/10-K/S-3/424B` 会映射到财报、现金跑道、稀释和估值等 Serenity 门槛。
- 历史 SEC 文件首次回填只作为证据，不伪装成当天新事件；无分类披露不进入重新验证队列。
- 当前测试总计 46 个通过。

## 下一轮优先级

1. 新闻与 SEC/财报披露矛盾检测：降低只追热点造成的误判。
2. ClinicalTrials.gov API 与 FDA 官方源：提高临床和监管事件覆盖。
3. 自动供应链/客户关系图：把 Serenity 的手工 JSON 逐步替换为带来源的关系边。
4. 逐条声明审计：每个关键结论必须能回到原文、日期和发布机构。
5. 至少积累 30 个股票-日期样本和 10 个独立预测日后再做初步判断；跨市场周期后才讨论稳定性。

## 安全边界

系统保持 research / dry-run / paper-only。所有分数是研究优先级或证据完整度，不是收益概率；
在样本不足、交易成本和选择偏差尚未充分评估前，不宣称具有预测能力。
